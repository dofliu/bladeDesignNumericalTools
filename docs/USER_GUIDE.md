# 使用說明

本工具用來做小型風力機的**概念設計與方案比較**:選轉子型式、設計葉片或外形,在虛擬風洞裡接上發電機與 MPPT 控制器跑時域模擬,最後產生報告。所有計算都在瀏覽器內完成。

## 1. 開啟

- 直接用瀏覽器(Chrome、Edge、Firefox、Safari 新版)打開 `dist/wind-turbine-designer.html`,或開啟部署好的 GitHub Pages 網址。
- 3D 場景需要連網載入 three.js;離線時 3D 風洞不顯示,但面板、圖表、計算、報告都能用。
- 第一次開啟會載入預設設計:水平軸 3 葉、半徑 1.5 m、設計尖速比 7、玻纖葉片、3.2 kW 發電機(已依轉子自動匹配)。

## 2. 畫面配置

| 區域 | 內容 |
|---|---|
| 頂部 | 水平軸/垂直軸切換、工作區分頁(或流程步驟)、版面切換、顯示/隱藏設定、匯出、深淺色 |
| 左側設定面板 | 四個步驟分頁:① 翼型 ② 轉子 ③ 風洞 ④ 負載 |
| 主畫面 | 目前的工作區:風洞、單葉片、流場或報告 |
| 風洞下方 | 分析圖表分頁:翼型與極曲線、葉片分析、性能曲線、即時監測、方案比較(可收合) |

### 兩種版面

- **經典版面**(預設):頂部是「風洞 / 單葉片 / 流場 / 報告」四個工作區分頁,設定面板四個步驟自由切換。
- **流程版面**:按頂部「流程版面」切換,改成依設計流程的五個步驟,每個步驟自動切到對應的工作區與設定分頁,可用「上一步 / 下一步」前進:

| 步驟 | 工作區 | 設定面板 | 做什麼 |
|---|---|---|---|
| ① 概念 | 風洞 | 轉子 | 選轉子家族(卡片)與基本尺寸,看 3D 外觀與整體性能 |
| ② 幾何 | 單葉片 | 轉子 | 調整葉片或外形幾何,看平面圖與剖面 |
| ③ 翼型 | 單葉片 | 翼型 | 選翼型、設定沿展長翼型站與極曲線 |
| ④ 虛擬風洞 | 風洞 | 風洞 | 設定風速、紊流與負載,觀察轉子與發電機動態 |
| ⑤ 比較與報告 | 報告 | — | 執行自動測試、產生報告、比較方案 |

版面選擇會記在瀏覽器裡,下次開啟沿用。

## 3. 選轉子家族

在流程版面的「① 概念」(或經典版面「轉子」分頁頂端)有轉子家族卡片,每張標示典型 Cp、最佳尖速比範圍、能否自行啟動與**模型可信度**。點選卡片即建立該家族的預設設計。

卡片下方的「我的形狀該選哪條路」依你的外形給建議:

1. **垂直軸升力型、可用半徑沿高度 r(z) 與扭轉描述** → 自訂外形(以 DMST 計算性能)
2. **有規律但現有模型算不了**(例如阿基米德螺旋)→ 參數化家族 + 匯入性能曲線
3. **完全自由的 CAD 外形** → 匯入 STL 外形 + 匯入性能曲線

| 家族 | 性能來源 | 說明 |
|---|---|---|
| 水平軸 n 葉 | BEM | 葉片數、半徑、設計尖速比、扭角與弦長都可調 |
| H 型 / 螺旋 / Φ / V | DMST | 直葉片、螺旋包角、彎曲葉片、V 型;多數需要輔助起轉 |
| 自訂外形 r(z) | DMST(延伸) | 以控制點描述外形;接近水平的段落只計阻力 |
| Savonius | 經驗曲線 | 阻力型,低尖速比、高起動轉矩 |
| 匯入性能曲線 | 你提供的 Cp–λ | 任何算不了的外形都可以接上虛擬風洞 |
| 阿基米德螺旋 | 你提供的 Cp–λ | 本工具只產生外形(3D、STL),不計算氣動性能 |
| 匯入 STL 外形 | 你提供的 Cp–λ | 由 STL 算掃掠面積、質量與轉動慣量 |

最後三種家族在你匯入資料前,會先載入標示「示意,非實測」的範例曲線,報告也會註明。

## 4. 設定面板

### ① 翼型

- **翼型站**:沿展長最多 6 站,每站選一種翼型,站與站之間線性混合(水平軸);垂直軸使用單一翼型。
- **自訂 NACA 翼型**:輸入 4 或 5 位數代號。
- **匯入翼型資料庫座標**:貼上或選擇 Selig / Lednicer 格式的 `.dat`。
- **極曲線模型**:預設為半經驗模型;可貼上 XFOIL 極曲線取代某翼型的估算值(介面會標示資料來源)。

### ② 轉子

- **水平軸**:設計點(設計風速、尖速比、攻角)與弦長、扭角設計方式(BEM 最佳化 / Schmitz 解析 / 線性)、製造修正(弦長/扭角縮放、最大弦長、線性化)、材料。截面表可逐一覆寫。
- **垂直軸**:型式、半徑、高度、葉片數、弦長、槳距、螺旋包角、支撐臂;可勾選動態失速與流線彎曲修正(簡化模型,預設關閉)。
- **自訂外形 r(z)**:側視預覽圖可直接編輯——
  - 拖曳控制點改變外形(放開後重新設計)
  - 雙擊空白處新增控制點,雙擊控制點刪除
  - 點選控制點後用方向鍵微調(上下改高度 ±0.01、左右改半徑 ±0.02,按住 Shift 為 5 倍),Delete 刪除
  - 也可以直接編輯下方 `zf, rf` 文字表(zf 為 0–1 的相對高度且需遞增,rf 為最大半徑 R 的倍數),或套用內建樣板
- **性能曲線(匯入資料)**:貼上或匯入 CSV,每行 `λ, Cp`(可加第三欄 Cq,可含標題列)。λ 須遞增;Cp 超過 Betz 極限 0.593 會警告。另需設定特徵半徑(λ 的基準)、高度或掃掠面積、質量、轉動慣量。
- **阿基米德螺旋**:外徑、軸向長度、葉片數、每片圈數、板厚、輪轂直徑、錐形比例、材料。
- **匯入 STL 外形**:上傳 `.stl`(ASCII 或 binary,上限 30 MB / 40 萬個三角形,超過 10 萬面會提醒可能變慢),選擇單位(mm/cm/m/in)、旋轉軸(X/Y/Z)與材料密度。面板會顯示最大半徑、軸向長度、掃掠面積、體積、質量、轉動慣量;網格未完全閉合時會警告(體積與慣量可能不準)。**STL 檔不會存進方案,重新整理頁面後需要重新上傳。**
- **轉子摘要**:Cp,max、最佳尖速比、掃掠面積、質量、噪音與成本概估、性能來源與可信度。

### ③ 風洞

來流風速、紊流強度、空氣溫度與海拔(決定空氣密度)、風向、偏航模式(自動對風或固定機艙角)與偏航速率、模擬時間倍率。陣風用主畫面「快速調整風洞」的「施加陣風」按鈕施加。

主畫面的「快速調整風洞」也可以直接改風速、風向、紊流、MPPT 控制方式,並有「施加陣風」「轉到最佳轉速」按鈕(手機版也能用)。

### ④ 負載

- **發電機**:預設依轉子自動匹配反電勢常數與繞組電阻;可手動調整後按「立即重新匹配」。
- **負載**:電池充電(定電壓)或電阻負載。
- **MPPT 控制**:擾動觀察法 P&O、最佳尖速比(需風速計)、最佳轉矩 T = kω²、固定占空比(比較用)。
- **保護**:超速煞車(轉速上限)、發電機額定功率;以及預設關閉的三個選項——
  - **切出風速**:平均風速超過切出值時停機,降到重啟風速以下才恢復(兩者不同以免反覆啟停)
  - **主動變槳**(僅水平軸):額定以上順槳控制功率,取代降轉速
  - **側偏收尾**(僅水平軸):風速超過設定值時機艙側偏,降低受風面積

## 5. 工作區

### 風洞

3D 場景顯示轉子、煙流與偏航;右上角可切換視角(立體/正面/側面/俯視)、精簡/完整儀表、暫停。儀表即時顯示風速、偏航誤差、轉速、尖速比、Cp、氣動功率、輸出電力、轉矩、占空比。

下方圖表分頁:

- **翼型與極曲線**:壓力分布、極曲線(可選雷諾數)
- **葉片分析**:扭角、攻角、弦長、厚度沿展長分布
- **性能曲線**:Cp–λ、功率曲線、年發電量(可調平均風速與 Weibull 形狀參數 k,或匯入實測風速時間序列——每行一筆風速,可為 CSV,取每行最後一個數值)、成本單價
- **即時監測**:最近 60 秒的風速、轉速、功率、尖速比、Cp、占空比
- **方案比較**:見第 6 節

### 單葉片

- 水平軸:平面形狀與翼型配置、選定剖面的翼型與速度三角形、剖面疊圖、各剖面極曲線、沿展長氣動量(攻角、Cl、推力/轉矩分布…)與結構量(彎矩、合成應力與安全係數、揮舞撓度、截面積/慣性矩)。
- 垂直軸:側視外形與選取高度、俯視葉片位置與速度三角形、攻角與轉矩隨方位角變化、局部極曲線;可拖動方位角、高度與分析尖速比。
- Savonius / 匯入曲線類:俯視示意與 Cp–λ 曲線(沒有翼型剖面可分析)。

### 流場

- 翼型:面板法速度或壓力係數場與流線,標示邊界層轉捩點與分離點(失速區僅示意)。
- 轉子:水平軸致動盤流管(可疊加葉尖渦螺旋尾流)、垂直軸 DMST 上下風流管速度。

### 報告

1. 填寫專案名稱、作者、設計目標(選填)。
2. 勾選要包含的內容:虛擬風洞測試(功率曲線、偏航、紊流、陣風、啟動)、流場分析圖、方案比較。
3. 按「產生報告」;自動測試需要數秒到數十秒。
4. 「下載 HTML」存成單一檔案,或「列印 / 另存 PDF」。

報告包含:設計條件(含噪音、成本、可信度)、翼型與極曲線、葉片幾何、設計點氣動分析、葉片結構(水平軸)、轉子性能預測、虛擬風洞測試結果、流場分析、結論與建議、模型說明與限制。設計若再修改,請重新產生報告。

## 6. 方案比較

- 在「轉子」分頁的「方案比較」或「方案比較」圖表分頁按「儲存目前方案」,把目前設計存起來(存在這台電腦的瀏覽器裡)。
- 比較表每列的副標顯示家族、掃掠面積與模型可信度,欄位為 Cp,max、最佳 λ、高效區 λ 範圍(Cp ≥ 90% 最大值)、年發電量(理想 MPPT、限發電機額定)、AEP/掃掠面積、容量因數、起轉 Cq(低 λ 平均轉矩係數,越大越容易自行起轉)、噪音概估(50 m)、LCOE 概估;滑鼠移到欄位標題可看計算條件。圖表疊加各方案的 Cp–λ 與分布曲線。
- 可改名、刪除,或「載入」回來繼續修改。不同家族以**掃掠面積**為共同基準比較。

## 7. 匯出

頂部「匯出」:

| 項目 | 內容 |
|---|---|
| 截面幾何 CSV | 水平軸:各截面半徑、r/R、弦長、扭角、槳距、厚度比、翼型站;垂直軸:依型式輸出外形參數 |
| 極曲線 CSV | 目前檢視翼型在各雷諾數下的 Cl、Cd(攻角 −180°–180°,每 1°) |
| 性能曲線 CSV | Cp–λ、功率曲線 |
| 完整設計包 ZIP | 葉片 STL(mm)+ 上述 CSV + 翼型座標 |
| 螺旋葉片 STL | 阿基米德螺旋家族的全部葉片(mm) |

Savonius、匯入曲線、阿基米德螺旋與 STL 家族沒有翼型葉片幾何,葉片 STL 與 ZIP 選項不會出現(阿基米德螺旋改提供「螺旋葉片 STL」)。若瀏覽器沒有開始下載,可按「顯示內容供複製」手動複製文字內容。

## 8. 手機

手機版(寬度 860 px 以下)只提供**檢視**:3D 風洞、圖表、方案比較與報告都能看;設計面板是唯讀的,「快速調整風洞」仍可調風速、風向、紊流與控制方式。完整編輯請用桌面版。

## 9. 資料保存

- 方案、深淺色、版面選擇存在瀏覽器的 localStorage;清除瀏覽器資料會一併刪除,換電腦或瀏覽器不會帶過去。
- 匯入的 STL 與風速時間序列不存進方案;匯入的 Cp–λ 曲線會隨方案儲存。

## 10. 模型能做到什麼、不能做到什麼

適合概念設計與方案之間的相對比較,**不適合直接當作製造或認證依據**:

- 極曲線為半經驗模型(面板法 + 摩擦阻力 + 失速估計 + Viterna),不是 XFOIL;可貼上 XFOIL 或實驗極曲線改善精度。
- 垂直軸 DMST 的動態失速與流線彎曲只是簡化修正,高尖速比偏樂觀。
- 阿基米德螺旋、STL 外形、匯入曲線的性能完全取決於你提供的資料。
- 流場是位勢流與流管近似,不是 CFD。
- 結構只算水平軸葉片準靜態;疲勞只算葉根單一風況;噪音、成本為經驗估計。
- 電氣為準穩態模型,不含結構振動、塔影與地面邊界層。

製造前建議以 XFOIL / CFD 或實體風洞驗證關鍵數值。

## 11. 常見問題

- **3D 畫面一片空白**:確認可以連到 cdnjs.cloudflare.com(three.js);其他功能不受影響。
- **H 型 Darrieus 不轉**:升力型垂直軸通常無法自行啟動,這是物理現象;切換家族時程式會自動輔助起轉,也可按「轉到最佳轉速」。
- **水平軸 14 m/s 以上一直觸發保護**:固定槳距轉子在高風速下發電機壓不住,可在「負載 → 保護」啟用切出風速或主動變槳,或加大發電機額定。
- **下載沒有反應**:部分瀏覽器會擋下自動下載,請使用「顯示內容供複製」或報告的「列印 / 另存 PDF」。
- **重新整理後 STL 不見了**:STL 不存進瀏覽器,請重新上傳。
